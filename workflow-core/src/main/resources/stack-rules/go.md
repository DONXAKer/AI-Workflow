# Go — обязательные требования

## Обработка ошибок
- Все ошибки обрабатываются явно. Запрещено глотать `err` через `_`.
- Использовать `fmt.Errorf("context: %w", err)` для wrapping с сохранением стектрейса.
- Не использовать `panic` в library code — только в `main()` при инициализации или в тестах (`t.Fatal`).

## Структура кода
- Экспортируемые типы и функции должны иметь godoc комментарий.
- Интерфейсы определяются в пакете-потребителе, не в пакете-провайдере (small interfaces).
- Использовать `context.Context` первым параметром для всех I/O-операций.

## Конкурентность
- Защищать разделяемое состояние через `sync.Mutex` или channels.
- Goroutine leak: всегда иметь механизм завершения через context cancellation или done channel.
