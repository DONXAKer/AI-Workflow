# Python — обязательные требования

## Типизация
- Аннотации типов обязательны для всех публичных функций и методов (аргументы + возвращаемое значение).
- Использовать `from __future__ import annotations` для forward references в Python < 3.10.
- Для сложных типов использовать `TypeAlias` или `TypeVar`.

## Исключения
- Исключения должны быть специфичными — не `except Exception` без логирования.
- Логировать через `logging.exception(...)` или `logger.error(..., exc_info=True)` для стектрейса.
- Создавать кастомные исключения через наследование от `Exception`.

## Структура кода
- Публичный API модуля определять через `__all__`.
- Зависимости инжектировать через параметры (не глобальные переменные) — для тестируемости.
